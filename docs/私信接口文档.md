# 私信功能接口文档

## 一、接口概览

| 模块 | 接口路径 | 方法 | 说明 |
|------|----------|------|------|
| 私信 | `/message/send` | POST | 发送消息 |
| 私信 | `/message/history/{friendId}` | GET | 获取聊天记录 |
| 私信 | `/message/conversations` | GET | 获取会话列表 |
| 私信 | `/message/read/{friendId}` | PUT | 标记消息已读 |
| 私信 | `/message/unread` | GET | 获取未读消息数量 |
| 私信 | `/message/{messageId}` | DELETE | 删除消息 |
| 好友 | `/friend/request/{friendId}` | POST | 发送好友请求 |
| 好友 | `/friend/handle/{requestId}` | PUT | 处理好友请求 |
| 好友 | `/friend/list` | GET | 获取好友列表 |
| 好友 | `/friend/requests` | GET | 获取待处理请求 |
| 好友 | `/friend/{friendId}` | DELETE | 删除好友 |
| 好友 | `/friend/check/{friendId}` | GET | 检查好友关系 |

---

## 二、消息模块 (Message)

### 2.1 发送消息
**请求**
```http
POST /message/send?toUserId={toUserId}&content={content}&type={type}
Content-Type: application/x-www-form-urlencoded
```

**参数说明**
| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| toUserId | Long | ✅ | - | 接收者用户ID |
| content | String | ✅ | - | 消息内容 |
| type | Integer | ❌ | 0 | 消息类型：0-文本，1-图片，2-语音 |

**响应示例**
```json
{
  "code": 1,
  "msg": "发送成功",
  "data": {
    "id": 12345,
    "fromUserId": 1001,
    "toUserId": 1002,
    "content": "你好呀！",
    "type": 0,
    "isRead": 0,
    "createTime": "2026-04-15T22:30:00"
  }
}
```

---

### 2.2 获取聊天记录
**请求**
```http
GET /message/history/{friendId}?limit={limit}
```

**路径参数**
| 参数 | 类型 | 说明 |
|------|------|------|
| friendId | Long | 好友用户ID |

**查询参数**
| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| limit | Integer | ❌ | 20 | 返回消息数量限制 |

**响应示例**
```json
{
  "code": 1,
  "msg": "success",
  "data": [
    {
      "id": 12340,
      "fromUserId": 1002,
      "toUserId": 1001,
      "content": "嗨~",
      "type": 0,
      "isRead": 1,
      "createTime": "2026-04-15T22:25:00"
    },
    {
      "id": 12345,
      "fromUserId": 1001,
      "toUserId": 1002,
      "content": "你好呀！",
      "type": 0,
      "isRead": 0,
      "createTime": "2026-04-15T22:30:00"
    }
  ]
}
```

**返回字段说明**
| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 消息ID |
| fromUserId | Long | 发送者用户ID |
| toUserId | Long | 接收者用户ID |
| content | String | 消息内容 |
| type | Integer | 消息类型：0-文本，1-图片，2-语音 |
| isRead | Integer | 已读状态：0-未读，1-已读 |
| createTime | String | 创建时间 |

---

### 2.3 获取会话列表
**请求**
```http
GET /message/conversations
```

**响应示例**
```json
{
  "code": 1,
  "msg": "success",
  "data": [
    {
      "userId": 1002,
      "lastMessage": "你好呀！",
      "lastTime": "2026-04-15T22:30:00",
      "unreadCount": 1
    },
    {
      "userId": 1003,
      "lastMessage": "明天见~",
      "lastTime": "2026-04-15T20:15:00",
      "unreadCount": 0
    }
  ]
}
```

**返回字段说明**
| 字段 | 类型 | 说明 |
|------|------|------|
| userId | Long | 好友用户ID |
| lastMessage | String | 最后一条消息内容 |
| lastTime | String | 最后消息时间 |
| unreadCount | Integer | 未读消息数量 |

**前端补充字段**（调用 `/friend/list` 匹配）
| 字段 | 类型 | 说明 |
|------|------|------|
| nickName | String | 好友昵称 |
| icon | String | 好友头像URL |

## 四、消息实体 (Message Entity)

### 数据库表结构
```sql
CREATE TABLE tb_message (
    id          BIGINT PRIMARY KEY AUTO_INCREMENT,  -- 主键
    from_user_id BIGINT NOT NULL,                    -- 发送者用户ID
    to_user_id   BIGINT NOT NULL,                    -- 接收者用户ID
    content      VARCHAR(2000) NOT NULL,              -- 消息内容
    type         TINYINT DEFAULT 0,                  -- 消息类型：0-文本，1-图片，2-语音
    is_read      TINYINT DEFAULT 0,                  -- 是否已读：0-未读，1-已读
    create_time  DATETIME DEFAULT CURRENT_TIMESTAMP  -- 创建时间
);
```

## 五、前端调用示例

### 5.1 发送消息
```javascript
// 发送文本消息
axios.post('/message/send?toUserId=1002&content=你好呀&type=0')
  .then(({data}) => {
    if (data.code === 1) {
      console.log('发送成功', data.data);
    }
  });

// 发送图片消息
axios.post('/message/send?toUserId=1002&content=https://xxx.com/img.jpg&type=1')
  .then(({data}) => {
    // ...
  });
```

### 5.2 获取聊天记录
```javascript
// 获取与用户1002的最近20条聊天记录
axios.get('/message/history/1002?limit=20')
  .then(({data}) => {
    if (data.code === 1) {
      this.messages = data.data;
      // 渲染消息列表
    }
  });
```

### 5.3 获取会话列表
```javascript
axios.get('/message/conversations')
  .then(({data}) => {
    if (data.code === 1) {
      this.conversations = data.data;
    }
  });
```

### 5.4 标记已读
```javascript
// 进入聊天页面时调用
axios.put('/message/read/' + friendId);
```

### 5.5 轮询未读消息
```javascript
// 每30秒轮询一次未读数
setInterval(() => {
  axios.get('/message/unread')
    .then(({data}) => {
      if (data.code === 1) {
        this.totalUnread = data.data;
      }
    });
}, 30000);
```

## 六、通用响应格式

所有接口均返回统一格式：

```json
{
  "code": 1,      // 状态码：1-成功，其他-失败
  "msg": "success", // 提示信息
  "data": {}       // 返回数据（可为null）
}
```

| code | 说明 |
|------|------|
| 1 | 成功 |
| 0 | 失败 |
